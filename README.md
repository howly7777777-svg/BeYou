# BeYou — GitHub Pages

Legal and support pages for **Be You Want to Be** iOS app.

## Deploy to GitHub Pages

1. Create a repository named `BeYou` on GitHub (account: `howly7777777`)
2. Push this folder's contents to the repo root
3. Go to **Settings → Pages → Source → Deploy from branch `main` / root**
4. Your site will be live at: **https://howly7777777.github.io/BeYou/**
